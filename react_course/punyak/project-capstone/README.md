### Capstone Project
> A small full-stack app that forces them to combine everything:
- Multi-page app with React Router, Auth flow (login/protected routes) hitting their Flask backend, Form with validation, connected to a REST API
- List/detail views with loading and error statesAt least one custom hook and one piece of global state (Context or Redux/Zustand)
- Basic tests for 2–3 components

Suggested project ideas: a mini job board, a ticket/issue tracker, or an inventory management tool — all pair well with what they already built in Python/Flask.
